## Принцип сборки

**Слоты = rubx.ru. Содержание = RUBIN (статья + TG).**

Порядок на rubx.ru: hero → что такое → свойства → схема → где используется → ресурсы/прозрачность → новости → «новая эпоха» → где получить → CTA → новички / FAQ / шаги.

Поверх каркаса добавлены слои, которых у RUBx нет, но они обязательны для RUBIN (иначе продукт неузнаваем): биржа перпов, AI-агент, White Label/API, дев-платформа, RUB1. Они стоят **после** базового объяснения и **до** CTA — не вместо rubx-слотов.

**Фокус v1 — B2C:** частный трейдер и квалифицированный инвестор, который торгует сам. Всё, что адресовано банкам, брокерам, партнёрам по White Label и внешним разработчикам, из макета v1 снято и ждёт своей очереди. Это касается не только целых блоков, но и вкраплений внутри оставшихся: пунктов навигации, CTA, карточек и колонок футера.

Новички (`17`–`19`) — только в нижней трети. Футер — в `19`.

## 1. Бриф (проверяемые факты)

1. Собственный L1, mainnet, EVM — год своей архитектуры вместо чужой сети.  
2. Стек целиком у Rubin: L1, движок, исполнение/расчёты, API, смарт-контракты, инструменты запуска финсервисов.  
3. Мотив: независимые контуры, когда доступ зависит от географии, а не от технологии.  
4. Первый продукт — DEX перпов (BTC, ETH, HYPE и др.; кросс-маржа; market/limit/SL/TP). Плечо — **до 5x** (TG: «3–5x», «до 5x» 25.04, «x5» 02.08 — самое свежее упоминание).  
5. Вход: WalletConnect или email; пополнение USDC через Ethereum/Arbitrum; газ за депозит — за счёт платформы.  
6. «DEX на своём L1 и инфраструктура для запуска криптопроектов»; одна из первых крипто-инфр в России (формулировка TG).  
7. API / White Label для банков, брокеров, финтеха.  
8. Общая ликвидность сети + сетевой эффект.  
9. 8 типов продуктов для независимых команд + SDK + UI Builder.  
10. AI-агенты через MCP (стакан, свечи, балансы, ордера; чат/голос); агент «Рина»; лимиты риска.  
11. Программируемые расчёты; **RUB1** — план («должен стать»), не живой модуль.  
12. Регуляторика РФ: закон 04.08.2026, основные нормы с 01.09.2026.  
13. Команда: опыт высоконагруженных сервисов Яндекса + финтех/банки/регулирование.  

Метрик масштаба (объём, TVL, пользователи) нет — **TBD**. Реф-программа (до 40% комиссий) — факт TG, на лендинг по желанию.
